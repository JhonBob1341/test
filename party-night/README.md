# After Hours

Single-player NSFW taboo dating game. You are at the first big college house party of the year with three 21+ best friends — Maya, Riley, and Jade. Choose who to chase, how filthy to get, and whether to keep a secret… or detonate the friend group.

## Run

```bash
npm install
npm run dev
```

## Play

- Confirm 21+
- Pick a name
- Branch through flirtation, risk, and NSFW scenes
- Affection meters drive solo / messy / caught / group endings
